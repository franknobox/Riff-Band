# 数据、版权、隐私与科研治理

## 1. 数据分级

| 等级 | 例子 | 默认处理 |
|---|---|---|
| Public | 开放元数据、公开宏观指标 | 云端可处理，保留来源/版本/许可 |
| Licensed | WRDS、CSMAR、Wind、机构全文 | 仅授权用户；不向外部模型发送；不再分发 |
| Sensitive | 去标识个体、医疗、调查微观数据 | 本地/隔离执行；严格 RBAC 与审计 |
| Restricted | 可识别个人、商业秘密、未公开数据 | 默认阻塞；需 IRB/DUA/组织批准与专用环境 |

## 2. Data Contract 必填

- 来源、URL、访问主体、许可证/DUA；
- 快照/版本、时间覆盖、地域、观察单位；
- 变量、单位、缺失码、连接键、采样与权重；
- PII 等级、伦理/IRB 状态、保留和删除策略；
- 是否可发送到第三方模型、是否可导出/共享；
- 数据质量检查和已知偏差；
- 输出最小聚合与披露控制。

## 3. 文献版权

- 平台保存元数据、用户有权访问的全文指针和抽取定位；不建立未经授权的全文仓库。
- OA 发现优先使用合法开放版本；预印本与最终版建立版本关系。
- 生成内容只保留必要短摘和定位，不长篇复制受版权保护文本。
- 团队上传全文前必须确认个人/机构访问权；导出研究包不自动包含受限 PDF。

## 4. LLM 数据边界

- 每个 model provider 配置数据处理区域、保留策略和是否用于训练。
- Licensed/Sensitive/Restricted 默认禁止进入外部 LLM；可使用本地模型或只传去标识结构化摘要。
- Prompt/response 日志按同等数据等级管理；敏感字段先脱敏。
- 模型输出是建议，不是事实；所有关键字段记录证据层级与人工验证状态。

## 5. 科研诚信

- 禁止伪造论文、DOI、数据、统计量、实验或审稿记录。
- 探索性分析与预注册/验证性分析分开标识。
- 协议修改、排除样本、指标变更和停止规则变化写入审计。
- 生成式 AI 的参与、模型/提示版本和人工责任按目标期刊政策披露。
- 负结果、失败诊断和反证不能被 Writer Agent 隐藏。

## 6. 安全控制

- OIDC、组织/项目/数据/运行级 RBAC；服务账号最小权限。
- 密钥由 secret manager 提供短期凭证；禁止 `.env` 上传和日志回显。
- 沙箱默认无网络、非 root、只读镜像、资源配额、输出白名单。
- 所有下载和连接器记录请求者、目的、条款、时间和结果哈希。
- 数据删除包括对象、索引、缓存、日志和派生可识别资产，并保留最小审计凭据。

## 7. Stata 与商业软件治理

- Stata 使用用户/机构自带许可的 local/institution Runner；平台不保存序列号、授权码或安装介质。
- Runner Profile 只记录版本、edition、许可模式、并发席位、健康状态和管理员；任务并发不得超过许可范围。
- Restricted/Sensitive 数据默认在本地或机构 Runner 执行；只上传获许可的聚合结果、脱敏日志和 manifest。
- do-file 运行前做策略检查，默认阻塞外部进程、动态下载 ado、未批准 Python/Java、任意网络和越界路径。
- ado/package 必须记录来源、版本/日期、校验值和批准状态；不能在生产 Run 中临时安装后不留记录。
- `.smcl/.log` 可能泄露路径、标签或观测值，上传前按 Data Contract 分级和脱敏。

## 8. 人工审批与责任

- G0—G5 的决定必须绑定 human actor、角色、对象 revision/hash、检查清单、评论和时间。
- Agent 只能创建草案、patch 和 issue，不能提交为最终决定或批准。
- 用户修改研究资产产生新 revision；原始数据、原始日志和运行数值不可覆盖。
- 上游语义变更使下游批准失效，系统保留旧决定和触发原因，防止使用过期审批运行或发布。
- 个人项目的 single-reviewer 与团队 four-eyes 明确区分；高风险数据、主要因果结论和最终发布可以要求多人会签。

## 9. 审核清单

在 G2 前逐项确认：

- [ ] 访问权与项目成员一致
- [ ] 许可允许拟议处理、LLM 和导出方式
- [ ] PII/敏感等级与 IRB/DUA 已确认
- [ ] 数据保存区域、期限和删除责任人明确
- [ ] 样本与变量口径可审计
- [ ] 外部连接器和模型均在白名单
- [ ] 研究包不会包含受限原始数据/全文
- [ ] Stata/商业软件许可、Runner 席位、ado 来源和日志脱敏已确认
- [ ] G2 批准绑定当前 Data Contract revision/hash，批准人不是 Agent
