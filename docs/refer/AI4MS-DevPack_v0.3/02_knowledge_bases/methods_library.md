# 管科研究方法库

> 每张卡片都必须与研究问题、数据生成过程和识别/求解目标匹配；工具不替代研究设计。

## M01 描述统计与探索性数据分析

- 方法族/分支：基础统计 / 共享基础
- 目标：理解分布、缺失、异常、关联与数据生成过程
- 数据：结构化或半结构化样本
- 核心假设：样本定义一致；统计口径可比
- 工作流：口径表→缺失/异常→分布→分组→相关→可视化→异常说明
- 诊断：缺失机制、极端值、重复记录、单位与时间对齐
- 稳健性：替代口径、缩尾/稳健统计、分层描述
- 推荐工具：pandas/Polars; R tidyverse; DuckDB
- 公式卡：STAT-01
- 常见失败：把相关性当因果，或在清洗前就开始建模

## M02 OLS/GLM 回归

- 方法族/分支：统计实证 / 实证解释
- 目标：估计条件相关或广义响应关系
- 数据：截面、面板或计数/二元结果
- 核心假设：线性/链接函数正确；误差与解释变量关系满足估计要求
- 工作流：理论→变量→基准式→估计→诊断→替代式→解释
- 诊断：残差、异方差、共线性、聚类结构、过度离散
- 稳健性：稳健/聚类标准误、替代因变量、非线性、删样本
- 推荐工具：statsmodels; R fixest/glm
- 公式卡：STAT-02; STAT-03; STAT-04
- 常见失败：只报告显著性，不报告效应量、区间与实际意义

## M03 面板固定效应/随机效应

- 方法族/分支：统计实证 / 实证解释
- 目标：控制不可观测个体或时间不变异质性
- 数据：个体×时间面板
- 核心假设：严格外生或给定效应下外生；组内变异足够
- 工作流：面板审计→FE/RE 选择→双向效应→聚类误差→动态/滞后检验
- 诊断：组内变异、序列相关、横截面相关、短面板偏误
- 稳健性：双向聚类、趋势项、滞后、Arellano-Bond/系统 GMM
- 推荐工具：linearmodels; R fixest/plm
- 公式卡：STAT-04
- 常见失败：固定效应吸收了核心变量后仍强行解释

## M04 结构方程模型/PLS-SEM

- 方法族/分支：测量模型 / 实证解释
- 目标：估计潜变量、测量关系与结构路径
- 数据：问卷、量表、多指标构念
- 核心假设：构念有效；样本与估计器匹配；模型可识别
- 工作流：理论构念→量表→预测试→测量模型→结构模型→中介/调节
- 诊断：信度、聚合/区分效度、共同方法偏差、拟合
- 稳健性：替代测量、竞争模型、多群组、不变性检验
- 推荐工具：R lavaan/seminr; Mplus; SmartPLS
- 公式卡：STAT-06
- 常见失败：用 PLS 规避糟糕测量，或用拟合指标替代理论

## M05 生存分析/风险模型

- 方法族/分支：事件过程 / 实证解释
- 目标：分析事件发生时间与删失
- 数据：持续时间、事件状态、协变量
- 核心假设：删失机制合理；比例风险等模型假设可检验
- 工作流：定义起点/事件→删失→KM→Cox/AFT→时变协变量→预测
- 诊断：比例风险、竞争风险、信息性删失
- 稳健性：AFT、分层 Cox、Fine-Gray、替代时间窗
- 推荐工具：lifelines; scikit-survival; R survival
- 公式卡：STAT-05
- 常见失败：忽略左截断、重复事件或竞争风险

## M06 双重差分与事件研究

- 方法族/分支：因果推断 / 因果识别
- 目标：估计政策/冲击对处理组的平均影响
- 数据：处理组、对照组、处理时间、面板/重复截面
- 核心假设：平行趋势、无提前反应、无干扰；分期处理需正确估计
- 工作流：DAG→处理定义→样本→动态效应→平行趋势→异质性→安慰剂
- 诊断：预趋势、处理时点异质、组别构成、溢出
- 稳健性：Callaway-Sant'Anna/Sun-Abraham、替代对照、placebo
- 推荐工具：R did/fixest; Stata csdid; Python linearmodels
- 公式卡：CAUS-02; CAUS-03
- 常见失败：对分期处理直接使用传统 TWFE 并误读权重

## M07 工具变量/2SLS

- 方法族/分支：因果推断 / 因果识别
- 目标：处理内生性并估计局部平均处理效应
- 数据：结果、内生处理、工具变量、控制变量
- 核心假设：相关性、排除限制、独立性、单调性
- 工作流：机制/DAG→一阶段→弱工具检验→2SLS→过识别→LATE 解释
- 诊断：第一阶段 F、弱工具、排除限制、异质效应
- 稳健性：LIML、不同工具、Conley bounds、负向对照
- 推荐工具：linearmodels IV; R AER/fixest; Stata ivreg2
- 公式卡：CAUS-04
- 常见失败：只证明工具相关，不论证排除限制

## M08 回归不连续设计

- 方法族/分支：因果推断 / 因果识别
- 目标：利用阈值规则识别局部因果效应
- 数据：运行变量、阈值、处理状态、结果
- 核心假设：阈值附近连续、不可精确操纵、函数形式局部有效
- 工作流：制度规则→带宽→图形→局部多项式→密度/协变量检验→稳健性
- 诊断：McCrary 密度、协变量平衡、带宽、donut RDD
- 稳健性：多带宽/核、局部随机化、placebo cutoff
- 推荐工具：R rdrobust; Python rdrobust
- 公式卡：CAUS-05
- 常见失败：高阶全局多项式造成虚假跳跃

## M09 合成控制

- 方法族/分支：因果推断 / 因果识别
- 目标：为单个或少数处理单位构造反事实
- 数据：长处理前序列、供体池、处理后结果
- 核心假设：供体池未受处理；处理前拟合充分；无强溢出
- 工作流：供体池→预测变量→权重→前期拟合→后期差距→置换检验
- 诊断：RMSPE、供体权重集中、处理前拟合、溢出
- 稳健性：leave-one-out、augmented SC、matrix completion
- 推荐工具：R Synth/augsynth; Python SyntheticControlMethods
- 公式卡：CAUS-06
- 常见失败：供体池不合格或前期拟合差仍宣称因果

## M10 DML/因果森林与异质效应

- 方法族/分支：因果机器学习 / 因果识别
- 目标：在高维控制下估计 ATE/CATE
- 数据：个体级处理、结果、高维协变量
- 核心假设：重叠、无未观测混杂或有效工具；交叉拟合正确
- 工作流：DAG→样本分割→nuisance 模型→正交化→ATE/CATE→校准
- 诊断：重叠、nuisance 误差、校准、CATE 稳定性
- 稳健性：不同 learner、敏感性分析、honest splitting
- 推荐工具：EconML; DoubleML; grf
- 公式卡：CAUS-08
- 常见失败：把异质性排序当成已验证的个体因果效应

## M11 实验室/现场/在线随机实验

- 方法族/分支：实验 / 因果识别
- 目标：通过随机化估计干预效应与机制
- 数据：处理分配、结果、预注册指标
- 核心假设：随机化有效；SUTVA；流失与不依从可处理
- 工作流：理论→预注册→功效→随机化→操纵→估计→多重检验→外部效度
- 诊断：平衡、操纵检验、流失、不依从、干扰
- 稳健性：ITT/TOT、随机化推断、分层、替代指标
- 推荐工具：R DeclareDesign; statsmodels; Qualtrics/oTree
- 公式卡：EXP-01; EXP-02
- 常见失败：事后改主指标、低功效或多重比较未校正

## M12 案例研究/访谈/扎根理论

- 方法族/分支：定性研究 / 探索与理论生成
- 目标：解释新现象、过程与机制并生成理论
- 数据：访谈、档案、观察、过程资料
- 核心假设：理论抽样合理；证据链与反例处理透明
- 工作流：研究边界→理论抽样→协议→编码→范畴→机制→跨案例→饱和
- 诊断：编码一致性、负例、三角验证、研究者反思
- 稳健性：替代解释、成员核验、审计轨迹、不同编码者
- 推荐工具：NVivo/Atlas.ti; Python/R text tooling
- 公式卡：无单一核心公式
- 常见失败：把少数案例频数化，或没有证据链就做普遍因果主张

## M13 系统综述/文献计量/元分析

- 方法族/分支：证据综合 / 证据综合
- 目标：系统识别、编码并综合研究结论
- 数据：文献记录、效应量、编码表
- 核心假设：检索与纳排可复现；效应量可比；偏倚可评估
- 工作流：协议→多库检索→去重→筛选→编码→质量→综合→偏倚→议程
- 诊断：覆盖率、双人一致性、发表偏倚、异质性
- 稳健性：替代检索式、leave-one-out、质量加权、p-curve
- 推荐工具：ASReview; revtools; metafor; bibliometrix
- 公式卡：META-01
- 常见失败：只用单一关键词/数据库，或把引用量当质量

## M14 设计科学研究/Action Design Research

- 方法族/分支：设计科学 / 设计构建
- 目标：构建并评估解决组织问题的人工制品
- 数据：需求证据、构件日志、评估指标与场景数据
- 核心假设：问题重要；设计知识可抽象；评估与主张匹配
- 工作流：问题→设计目标→构件→原型→评估→迭代→设计原则
- 诊断：效用、可用性、技术正确性、场景适配、可迁移性
- 稳健性：多场景评估、基线、消融、对抗/极端案例
- 推荐工具：Git; experiment harness; UX analytics
- 公式卡：DSR-01
- 常见失败：只做软件开发，没有研究问题、评估和可迁移设计知识

## M15 线性规划/混合整数规划

- 方法族/分支：运筹优化 / 规范决策
- 目标：在约束下求最优资源配置与计划
- 数据：参数、决策变量、目标、约束
- 核心假设：线性关系；参数口径一致；可行域与整数性正确
- 工作流：业务规则→变量→目标→约束→小例验证→求解→gap→敏感性
- 诊断：可行性、最优 gap、规模、对偶值、约束绑定
- 稳健性：替代目标/权重、场景、松弛、warm start
- 推荐工具：Pyomo/PuLP/OR-Tools; Gurobi/CPLEX/HiGHS
- 公式卡：OPT-01; OPT-02
- 常见失败：模型可解但业务不可执行，或把单位/索引写错

## M16 随机规划/鲁棒优化/机会约束

- 方法族/分支：运筹优化 / 规范决策
- 目标：在不确定性下给出可控风险的决策
- 数据：场景/不确定集合/概率分布、成本与约束
- 核心假设：不确定性表示与业务风险一致；样本外可验证
- 工作流：不确定源→场景/集合→两阶段/鲁棒模型→求解→样本外→保守度
- 诊断：样本外违约率、VSS/EVPI、价格鲁棒性、分布漂移
- 稳健性：不同集合半径、bootstrap 场景、DRO、stress test
- 推荐工具：Pyomo; CVXPY; Gurobi; RSOME
- 公式卡：OPT-03; OPT-04; OPT-05
- 常见失败：在训练场景内漂亮、样本外失效；鲁棒半径任意

## M17 动态规划/MDP/强化学习

- 方法族/分支：动态决策 / 规范决策
- 目标：在状态随时间演化时学习最优策略
- 数据：状态、动作、转移、奖励、折扣/终止
- 核心假设：马尔可夫性近似成立；奖励与真实目标一致；离线数据覆盖
- 工作流：状态/动作→Bellman→基线策略→求解/学习→离线评估→安全约束
- 诊断：收敛、策略价值、覆盖、分布外动作、奖励黑客
- 稳健性：替代奖励、保守离线 RL、模拟器、策略约束
- 推荐工具：Gymnasium; Stable-Baselines3; Ray RLlib; JAX/PyTorch
- 公式卡：STO-04; ML-05
- 常见失败：只看累计奖励，不检查可解释性、安全与分布外风险

## M18 排队论/离散事件仿真/仿真优化

- 方法族/分支：随机系统 / 规范决策
- 目标：评估拥堵、容量、服务和随机流程
- 数据：到达/服务分布、流程、资源、策略
- 核心假设：到达服务过程有可辩护模型；稳态/热身处理正确
- 工作流：流程映射→分布拟合→模型→验证→实验设计→置信区间→优化
- 诊断：守恒关系、热身期、独立重复、校准、极端负载
- 稳健性：替代分布、压力场景、方差缩减、仿真优化
- 推荐工具：SimPy; AnyLogic; Arena; simmer
- 公式卡：STO-01; STO-02
- 常见失败：单次仿真当结论，或不做真实系统校准

## M19 网络流/选址/路径与调度

- 方法族/分支：组合优化 / 规范决策
- 目标：优化物流、交通、网络设计和资源时空匹配
- 数据：图、需求、容量、成本、时间窗
- 核心假设：网络与约束真实；规模与求解策略匹配
- 工作流：图建模→基准 MILP→分解/启发式→算例→真实实例→敏感性
- 诊断：可行率、最优 gap、运行时、不同规模、业务 KPI
- 稳健性：多初值、精确算法对照、消融、扰动测试
- 推荐工具：OR-Tools; NetworkX; PyVRP; Gurobi
- 公式卡：OPT-06; OPT-07; OPT-08
- 常见失败：只和弱基线比较，或测试实例与真实规模不匹配

## M20 库存/收益管理/定价

- 方法族/分支：运营模型 / 规范决策
- 目标：平衡缺货、持有、容量与价格收益
- 数据：需求分布、成本、提前期、容量、价格响应
- 核心假设：需求和成本估计可用；政策边界清晰
- 工作流：需求→成本→基准模型→最优政策→估计/校准→仿真→敏感性
- 诊断：服务水平、缺货/积压、估计误差、非平稳性
- 稳健性：分布鲁棒、滚动窗口、情景、行为偏差
- 推荐工具：Pyomo; scipy; inventory/forecast packages
- 公式卡：OPT-09; OPT-10
- 常见失败：用历史均值代替需求不确定性，或忽略执行约束

## M21 博弈论/机制设计/契约

- 方法族/分支：解析建模 / 机制解释
- 目标：解释战略互动并设计激励、平台或供应链机制
- 数据：参与者、行动、信息、效用/利润、时序
- 核心假设：理性与信息结构适配；均衡存在/唯一性与边界明确
- 工作流：参与者→时序→收益→均衡→比较静态→福利→机制设计→数值校准
- 诊断：均衡多重性、参数边界、参与约束、社会福利
- 稳健性：替代时序/信息、行为偏差、经验校准、数值全局搜索
- 推荐工具：Mathematica/Maple; SymPy; scipy/JAX
- 公式卡：GAME-01; GAME-02; GAME-03
- 常见失败：数学均衡漂亮但参数区间不现实、管理含义不可执行

## M22 离散选择/需求与结构模型

- 方法族/分支：结构估计 / 机制解释
- 目标：估计偏好、替代关系与反事实政策
- 数据：个体/市场选择、属性、价格、可用集合
- 核心假设：效用设定合理；选择集正确；价格内生性处理
- 工作流：效用→选择集→识别→估计→拟合→弹性→反事实→福利
- 诊断：IIA、弱识别、价格内生、外部有效性
- 稳健性：mixed logit、工具变量、不同市场定义、holdout
- 推荐工具：PyLogit; Biogeme; R mlogit; pyblp
- 公式卡：DEMAND-01
- 常见失败：遗漏选择集或忽略价格内生性

## M23 ARIMA/VAR/状态空间

- 方法族/分支：时序预测 / 预测与解释
- 目标：预测单变量或多变量动态并分析冲击
- 数据：等频时序、外生变量、足够历史
- 核心假设：平稳/协整与误差结构可检验；无未来泄漏
- 工作流：时间切分→平稳性→基线→识别→估计→残差→滚动回测
- 诊断：ACF/PACF、单位根、残差白噪声、结构突变
- 稳健性：滚动窗、不同滞后、状态空间、结构断点
- 推荐工具：statsmodels; sktime; R forecast/fable/vars
- 公式卡：TIME-01; TIME-02
- 常见失败：随机打乱时序交叉验证造成信息泄漏

## M24 监督学习/集成学习

- 方法族/分支：机器学习 / 预测计算
- 目标：预测分类、回归、排序或风险
- 数据：特征、标签、时间/组别结构
- 核心假设：训练与部署分布可比；标签与决策目标一致
- 工作流：任务→切分→特征→基线→训练→调参→评估→解释→监控
- 诊断：泄漏、校准、组别/时间外推、类别不平衡
- 稳健性：时间/组 CV、消融、外部测试、漂移与公平性
- 推荐工具：scikit-learn; XGBoost; LightGBM; CatBoost
- 公式卡：ML-01; ML-02
- 常见失败：只追求一个指标，不做基线、校准和决策价值评估

## M25 NLP/嵌入/主题与文本因果

- 方法族/分支：文本与生成式AI / 预测计算
- 目标：把论文、评论、公告和对话转为变量或预测
- 数据：文本、时间戳、作者/实体、标签或弱监督
- 核心假设：语料权限清楚；时间切分；标注有效；提示与模型版本可追踪
- 工作流：语料→清洗→标注→表示→模型→人工审计→稳定性→下游验证
- 诊断：标注一致性、漂移、幻觉、提示敏感、去标识化
- 稳健性：多模型/提示、人工复核、词典基线、时间外测试
- 推荐工具：spaCy; transformers; sentence-transformers; BERTopic
- 公式卡：ML-02; ML-04
- 常见失败：把 LLM 输出直接当真值，或无法复现模型/提示版本

## M26 社会/供应链/金融网络分析

- 方法族/分支：网络科学 / 解释与预测
- 目标：分析关系结构、传播、中心性与系统风险
- 数据：节点、边、权重、时间或多层关系
- 核心假设：边定义与缺失机制合理；网络边界清楚
- 工作流：关系定义→图构建→描述→中心性/社区→传播/因果→稳健性
- 诊断：边阈值、边界、同配性、置换、时间演化
- 稳健性：替代边定义、随机网络基线、留边/留点、动态网络
- 推荐工具：NetworkX; igraph; graph-tool; PyG
- 公式卡：NET-01
- 常见失败：把中心性当因果影响，或忽略网络采样偏误

## M27 贝叶斯层级模型

- 方法族/分支：贝叶斯 / 实证解释
- 目标：合并先验与数据、部分池化并传播不确定性
- 数据：多层/小样本/异质群组数据
- 核心假设：生成模型可辨识；先验可解释；采样收敛
- 工作流：DGP→先验→似然→后验采样→PPC→比较→决策
- 诊断：R-hat、ESS、发散、PPC、先验敏感性
- 稳健性：弱/强先验、不同层级、LOO-CV、模拟校准
- 推荐工具：PyMC; Stan; brms
- 公式卡：BAYES-01
- 常见失败：只报告后验均值，不做收敛与后验预测检查

## M28 主体仿真/系统动力学

- 方法族/分支：复杂系统 / 探索与规范
- 目标：研究涌现、反馈、扩散和非线性政策效果
- 数据：规则、主体、网络、状态、校准目标
- 核心假设：规则有证据基础；宏观模式可校准；不确定性透明
